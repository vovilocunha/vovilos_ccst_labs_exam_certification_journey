# vovilos_ccst_labs_exam_certification_journey
A collection of hands-on labs and practical notes created during my CCST (Cisco Certified Support Technician) exam preparation. It covers networking fundamentals, common protocols, troubleshooting approaches, basic network security, and real-world IT support scenarios, reflecting my personal study experience and learning process.

## 📌 Overview
This repository documents my preparation for the **CCST (Cisco Certified Support Technician)** exam by **Cisco**.
It includes hands-on labs, technical notes, and practical examples focused on networking fundamentals and IT support skills.

My goal is to build a solid technical foundation through practice, not just theory.

---

## 🧪 Topics Covered
- Network fundamentals and architectures  
- Common network protocols (IP, TCP/UDP, DNS, DHCP, HTTP/HTTPS,NAT, SNMP, OSPF, RIP, Syslogs, NTP, QoS, IPv4 and IPv6 etc.)  
- Wired and wireless networking basics  
- Troubleshooting methodologies and logical workflows  
- Basic network security concepts and best practices  
- Realistic IT support scenarios aligned with the CCST exam
